# UML Documentation

This folder contains the UML diagrams for the School ERP System.

## Files
- `use-case.puml`: system actors and major use cases
- `class-diagram.puml`: main domain entities and relationships
- `sequence-login.puml`: login authentication flow
- `sequence-my-portal.puml`: student/parent portal retrieval flow

## Render options
You can render these diagrams with:
- PlantUML VS Code extension
- PlantUML server
- Local PlantUML JAR

## Command example
```bash
plantuml docs/uml/*.puml
